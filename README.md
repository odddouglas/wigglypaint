# WigglyPaint (Odd Fork)

A wiggly, squiggly animated drawing surface — a juicy drawing tool for Decker.

Original by **John Earnest**. This is a modified ("odd") fork.

## 在线体验

GitHub Pages 部署后访问：

```
https://odddouglas.github.io/wigglypaint/
```

## 本地运行

直接用浏览器打开 `index.html` 即可，无需构建或安装依赖。

## 项目结构

```
wigglypaint/
├── index.html          # 单文件应用（Decker deck，含完整运行时）
└── README.md
```

> 说明：本项目是单个自包含的 HTML 文件（基于 [Decker](https://beyondloom.com/decker/) 格式），内含完整运行时，不依赖外部 CSS/JS/图片资源。

## 部署

推送到 GitHub 后，在仓库 `Settings → Pages` 中选择：

- Source: `Deploy from a branch`
- Branch: `main` / 目录 `/ (root)`
