# WigglyPaint (Odd Fork)

https://odddouglas.github.io/wigglypaint/

A wiggly, squiggly animated drawing surface — a juicy drawing tool for Decker.

Original by **John Earnest**. This is a modified ("odd") fork.

Simply open 'index. html' with a browser without building or installing dependencies.

```
wigglypaint/
├── index.html         
└── README.md
```

>Description: This project is a single self-contained HTML file (based on [Decker])（ https://beyondloom.com/decker/ ）Format), including complete runtime, does not rely on external CSS/JS/image resources.
